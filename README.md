# GeoVision

**Post-Disaster Building Damage Assessment from Satellite Imagery**

## Overview

GeoVision is a computer vision project that aims to identify and classify building damage by comparing pre-disaster and post-disaster satellite imagery.

## Planned Features

- Process pre-disaster and post-disaster image pairs.
- Predict building damage severity.
- Visualize predictions in an interactive map.
- Evaluate model performance using class-specific metrics.
- Export supported prediction results.

## Technology Stack

- Python
- PyTorch
- Computer vision and image-processing libraries
- Streamlit and Folium
- Git and GitHub

## Project Status

Initial development setup completed. Dataset inspection and validation are upcoming milestones.

## Responsible Use

GeoVision is intended as a research and decision-support tool. Predictions require human review and should not be treated as definitive assessments of disaster damage.
